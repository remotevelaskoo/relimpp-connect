## Princípios

1. O repositório é a fonte de verdade.
2. Documentação e código devem evoluir juntos.
3. Mudanças arquiteturais relevantes exigem ADR.
4. Novos módulos ou comportamentos complexos exigem RFC.
5. Toda entrega deve possuir escopo, critérios de aceite e rastreabilidade.
6. Segurança, autorização e auditoria são requisitos transversais.
7. Nenhuma Sprint é concluída sem atender à Definition of Done.
